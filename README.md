# Ogtech.no

Nettside for OgTech – Onsite Gas Technology.

`index.html` er en selvstendig side (HTML, CSS og JavaScript i én fil) med to forsideforslag som man kan bla mellom:

1. **Trygg drift** – kundeverdi først
2. **Onsite + Core** – teknologi og systemkompetanse først

Åpne `index.html` i en nettleser for å se siden.
